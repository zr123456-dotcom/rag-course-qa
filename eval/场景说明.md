# 场景说明：课程复习问答助手

> 版本：v2｜ 日期：2026-11-7 ｜ 当前语料：1 份（计划扩充到 5~10 份）

## 1. 用户是谁

本校软件技术相关专业的学生，临近期末，手里有一堆复习资料，
想快速查到某个考点的准确定义或区别，而不是翻几十页 PDF 去找。

典型场景：
- 复习时想起一个概念但记不清细节
- 想知道两个相似概念的区别（如 ArrayList vs LinkedList）
- 想确认某道题的标准答案要点

## 2. 他们会问什么

真实例子（来自我的复习经历）：

1. "期末考几种题型？每种多少分？"
2. "我直接调用run()能启动线程吗?"
3. "列表、集合、映射这三个概念有什么不同？"
4. "Java SE和Java EE分别是什么意思？"
5. "本次考试的时间和地点？"

## 3. 什么样的回答算"好"

- **直接给结论**，不铺垫、不寒暄
- **要点清晰**（列举题要分条列出，如三种实现类的对比）
- **必须标出来源**：文件名 + 页码，让用户能回原文核对
- **长度克制**：5 行以内，不展开无关内容
- 用户看到答案后，**能在 30 秒内回原文验证**

## 4. 什么绝对不能出错（红线，每条都可检验）

| # | 红线 | 检验方法 |
|---|---|---|
| 1 | 资料里没有的，必须说"没有"，不能编 | 不可答题的答案必须含拒答标志词（"无法回答"/"未提及"/"没有找到"） |
| 2 | 答案必须能溯源 | 返回结果里至少有 1 条来源带页码 |
| 3 | 涉及多个对象时，必须逐个说明，不得合并概括 | 期望关键词的覆盖率 ≥ 0.5（如三个实现类至少提到两个） |
| 4 | 答案长度 ≤ 5 行 | 换行数 ≤ 5（可选，属于"体验"要求而非正确性） |

## 5. 知识库范围（最重要）

### 算在内
- 《Java 高级编程》课程复习资料（10 页 有详细答案）
- 《数据采集》简答题资料（3 页 有详细答案）
- 《计算机组成原理》简答题/计算题考点范围（7 页 仅题目,无答案）
> 注意：计组资料只有考点题目、没有答案。
> 因此「计组考什么」可答，但「某个考点具体是什么」必须拒答。

### 不算在内（必须拒答）

| 类型 | 例子 |
|---|---|
| **教务信息** | 期末考试的具体日期、考场安排、成绩查询方式 |
| **学籍信息** | 学分、绩点、考核比例、补考规则 |
| **人员信息** | 任课教师姓名、联系方式、答疑时间 |
| **其他课程** | 未被收录进知识库的课程内容 |
| **无关技术问题** | 如"怎么配置 Nginx"、"Python 怎么装" |
| **超出课程深度** | 如"JVM 的 GC 算法源码实现细节" |

### ⚠️ 一个容易误判的边界

文档**第 3 页有"考试相关内容"章节**，但它讲的是**答题要求**（如"把所有类写在答题框中"），
**不是考试日期或安排**。

所以：
- "考试答题有什么要求？" → **可答**（在文档里）
- "考试是哪一天？" → **必须拒答**（不在文档里）

出题时要区分这两种。

### 更多易误判的边界

- 问"考试注意事项" → **可答**（第 3 页有答题要求）
- 问"补考怎么安排" → **拒答**（文档没提，属于教务信息）
- 问"泛型的作用" → **可答**（第 1、8 章）
- 问"Java 21 的虚拟线程" → **拒答**（超出课程范围，文档写的是基础多线程）

### ⚠️ 特殊边界：只有题目、没有答案

计组资料是"考点清单"，只有问题没有答案。因此：

- "计组的必考计算题有哪几类？" → **可答**（清单在文档里）
- "冯诺依曼体系结构包括哪些部分？" → **必须拒答**（问题原文在文档里，但答案不在）

这是最难的一类负样本：问题本身在文档中出现过，模型容易误以为"资料里有答案"。

## 7. 评估判定规则（对应第 4 项红线）

| 指标 | 定义 | 通过标准 |
|---|---|---|
| **检索命中** | 期望的文件 + 页码都出现在返回的 sources 里 | 命中 = 通过 |
| **关键词覆盖** | 期望关键词在答案中出现的比例 | ≥ 0.5 |
| **拒答正确** | 不可答题的答案含拒答标志词 | 必须通过 |
| **长度合规** | 答案换行数 | ≤ 5 行 |

### 拒答标志词（用于自动判定）

`无法回答` / `无法确定` / `没有找到` / `未提及` / `不包含` / `不知道` / `无法从资料`

### 综合通过判定

- 可答题：`关键词覆盖 ≥ 0.5` **且** `检索命中为 True`
- 不可答题：`拒答正确 = True`

### 已知局限

- 关键词覆盖是**代理指标**，可能出现"含关键词但意思错"的假通过
- 因此每轮评估都要**人工复核未通过的题**，确认是真失败还是判定过粗
